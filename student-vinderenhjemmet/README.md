# Studentfrivillig på Vinderenhjemmet

Publisert studentside for fleksible frivilligoppdrag på Vinderenhjemmet.

## Lokal kjøring

Kjør fra roten av `nettside_frivilligsentralen`:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Åpne `http://127.0.0.1:8765/student-vinderenhjemmet/`.

## Publisert side

`https://frivilligsentralen.org/student-vinderenhjemmet/`
