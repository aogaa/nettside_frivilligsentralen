# Gode stunder på Vinderenhjemmet

Publisert rekrutteringsside for løpende frivilligoppdrag på Vinderenhjemmet.

## Lokal kjøring

Kjør fra roten av `nettside_frivilligsentralen`:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Åpne `http://127.0.0.1:8765/gode-stunder-vinderenhjemmet/`.

## Publisert side

`https://frivilligsentralen.org/gode-stunder-vinderenhjemmet/`
